Introdução
O objetivo teve como foco a construção de um modelo conceitual para um sistema de locação de veículos. Essa modelagem foi feita com base em um diagrama de classes UML.

O Metodologia utilizada
Para a construção do modelo, utilizei Python e criei as classes e métodos realizando as seguintes passos:
Analisei os requisitos solicitados com base no diagrama.
Identifiquei as entidades envolvidas: veículo, modelo, marca, cliente e locação.
Determinei os relacionamentos.
Como mencionado no começo elaborei o script usando Python pela praticidade e pelo fato de ser menos verborrágico que outras linguagens que usam POO, foram criadas classes para o objeto carro que são: Marca, Modelo, Veículo. Os métodos são: Alugar e Devolver. Criei outras classes chamadas Cliente e Locação está ligada classe cliente e veículo, por último foi criado o método devolução.

Resultado
O resultado foi um diagrama de classes que representa fielmente os requisitos do sistema. Foram modeladas cinco classes principais com seus respectivos atributos e métodos. Os relacionamentos entre as classes foram definidos de forma a garantir a integridade das informações e permitir o controle sobre o processo de locação de veículos.

Conclusão
